# Shopify 历史经营分析工作坊

学员将一家虚拟服装零售商过去 12 个完整自然月的交易装入 BigQuery，再用订单、商品和库存回答经营问题。练习覆盖 2025-11-01 至 2026-10-31，金额统一为 USD。

## 数据来自哪里

2026-11-25 从 meet-wear-me 的 Shopify 后台分两页只读导出商品，在店铺常规设置中核实了基础币种 USD。商品表保留当日全部 63 件商品、536 个变体的原始名称、分类、选项、SKU 和目录价格。商品名称与后台类目可能不一致。336 个变体的 SKU 为空，另有多个变体共用 SKU。关联商品明细请使用工作坊生成的 variant_id。

虚拟门店从目录中选取已发布、状态为 active、属于服装类目、价格大于零且名称不含 test 的变体作为演示货盘，共 52 件商品、260 个变体。筛选结果在产品表中标记。其余变体可用于商品数据质量练习。订单使用同一份目录快照作为历史模拟基价，各期成交额由模拟数量和折扣计算。真实历史售价和真实库存不可从本数据包推断。

客户、订单、订单行、折扣和库存流量均为合成数据。客户仅有教学编号、首次购买日期与模拟获客渠道。数据制作仅访问商品目录及店铺币种设置。

## 文件与入仓基准

| 文件 | 一行代表 | 数据行数 |
|---|---|---:|
| products.csv | 一个商品变体 | 536 |
| customers.csv | 一位合成买家 | 1,359 |
| orders.csv | 一笔已成交的合成订单 | 1,904 |
| order_items.csv | 一笔订单中的一行商品 | 2,679 |
| inventory.csv | 一个演示货盘变体在一个月的库存流水汇总 | 3,120 |

## 给学员的导入指令

将下段指令和你有权限访问的数据目录链接交给 Antigravity。当前研发仓库为私有，学员需要对所给链接有读取权限。

> 读取此目录的五个 CSV 和 data_dictionary.md。按照数据字典核对列名、类型、主键及关联关系。告诉我已连接的 BigQuery 项目、目标数据集与拟创建的五张表。经我确认后再创建和加载，若目标表已存在则先停止。以 UTF-8 解析，跳过一行表头，空字段按 NULL 处理。完成后列出每张表的实际行数，并核对订单净销售额、销量、订单与明细金额差异、库存数量平衡。若授权不足，请说明失败步骤。

五表的文件级校验已通过。入仓后应得到销量 **2,898 件**，商品折前销售额 **2,089,243.90 USD**，折扣 **74,724.89 USD**，净销售额 **2,014,519.01 USD**。订单与明细的金额差异、库存数量差异均应为零。本版本已在本地逐行核对，BigQuery 实际建表与加载留作实战环节。

## 经营分析练习

1. 观察 2025 年 11 月末的订单和折扣。如何区分订单量增长与单笔订单净额变化？
2. 按月计算首购买家与回购买家，比较两个半年。月回购订单占比和全期买家复购率各回答什么问题？
3. 找出夏季销量突然归零、次月恢复的服装款式。用库存流水检验缺货解释，并说明现有数据能否量化损失的需求。

这些变化是教学设定。复购与库存的计算口径见[数据字典](data_dictionary.md)。
